## Important notes

- Public Domain and CC0 are used here as the closest practical meaning of "no copyright restrictions". Public-domain status and CC0 dedication are stated on each linked file page.
- Attribution is not legally required for these selected files, but creator and source details are retained here as a courtesy and for provenance.
- "Forest track 3" is footsteps on wet leaves, not a clean recording of leaves rustling in a tree canopy.
- "Howling wind" is a recording of wind howling inside a building.
- "Gunshots 8" is a simulated sound made with Audacity and popped balloons, not a recording of an actual firearm.
- A glass-breaking recording is not included yet. A candidate Freesound recording was found with CC0 licensing, but no stable, directly usable media file could be verified for this static site; it is safer to omit it than to ship a file with unclear provenance.
- The audio is streamed from Wikimedia Commons on demand. Playback requires an internet connection and depends on the source host remaining available.
