# مقام | Maqam Tuner

موالف ويب عربي (RTL) لضبط أوتار العود والجيتار والبزق والكمان الغربي والكمان الشرقي.

## المزايا
- واجهة عربية متجاوبة تعمل على الهاتف والحاسوب.
- تحليل الصوت من الميكروفون باستخدام Web Audio API وارتباط ذاتي لاكتشاف التردد الأساسي.
- عرض اسم النغمة والأوكتاف والتردد بالهرتز والانحراف بالسنت.
- أنماط ضبط شائعة قابلة للاختيار لكل آلة، مع نغمة مرجعية مسموعة.
- تعديل تردد أي وتر بالنقر المزدوج على بطاقة الوتر.
- رسائل واضحة عند رفض إذن الميكروفون أو عدم وجود جهاز.

## التشغيل
لا توجد حزم أو عملية بناء مطلوبة. افتح `index.html` عبر خادم محلي مثل:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

**الميكروفون:** يتطلب المتصفح إذناً صريحاً واتصالاً آمناً عبر HTTPS أو localhost. إذا رفضت الإذن، اسمح به من إعدادات الموقع وأعد المحاولة.

## ملاحظات الضبط
الترددات الافتراضية مراجع تقريبية لأن الضبط قد يختلف حسب الآلة والمدرسة وعدد الأوتار. يظهر ذلك خصوصاً في العود والبزق والكمان الشرقي. لا تعتبر الإعدادات الشرقية معياراً موحداً؛ عدّل الترددات بالنقر المزدوج على الوتر لتوافق مرجعك الموسيقي.

## الملفات
- `index.html`: بنية الصفحة ومحتواها العربي.
- `styles.css`: التصميم المتجاوب.
- `app.js`: الإعدادات، كشف النغمة، وإنتاج النغمة المرجعية.

## الخصوصية
يعالج المتصفح الصوت محلياً أثناء جلسة الضبط. لا يرفع التطبيق الصوت إلى خادم ولا يحتاج إلى مفاتيح API.


## قسم المقامات
- اختيار مقامات بيات، كرد، صبا، سيكا، عجم، نهاوند ورست.
- لوحة بيانو تفاعلية تضيء درجات المقام ويمكن عزف كل مفتاح منها.
- دعم علامات أرباع الصوت (مثل مي نصف بيمول) بمفاتيح افتراضية بين المفاتيح المعتادة وتشغيل ترددها الدقيق.
- عرض درجات المقام وأبعاد المسافات بينها، مع إمكانية نقل المقام إلى طبقة أخرى.
- الصيغ المعروضة تعليمية صاعدة وقد تختلف التفاصيل حسب المدرسة الموسيقية.
